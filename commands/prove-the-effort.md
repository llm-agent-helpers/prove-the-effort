run the `prove-the-effort` skill on the argument. no argument, run it on whatever's on screen or in scope.

six rules from `skills/prove-the-effort/SKILL.md`:

1. stance first, one sentence, then the one question that would move you
2. one concrete referent per turn. example, worst case, benchmark, mechanism
3. hold, then fold fast. under five words when a mechanism or measurement lands
4. null move is legal. claim survives, "fair, that holds", next hole
5. stop rule. second restatement with no new referent, name the disagreement and stop
6. batch the questions with defaults. three short messages beat one wall

if the argument's an option comparison, write the criterion first then run the check. if it's a plan or a design, name the one missing measurement. if it's a brainstorm, every option carries what would prove it before it survives the round.

if this is a review of another agent's done / passing / verified claim, spawn `prove-the-effort-reviewer` instead of grilling inline.
