# evolution log: prove-the-effort

dated deltas. when one of these disagrees with SKILL.md the delta wins.

## 2026-09-22, the name
- rule: one name for all of it. the plugin, the skill, the slash command, the reviewer subagent, all `prove-the-effort`. prove-me-wrong, find-the-gap, cut-the-waste, worth-building are all retired.
- why: the name has to tell someone who's never used it what the job is. prove the effort is the job. every claim, plan, brainstorm, review or "done" report names the one thing that'd show the effort's feasible, optimal and worth spending.
- how to apply: every install path, trigger phrase, agent hook and doc uses prove-the-effort. nothing carries an alias.
- promoted: 2026-09-22

## 2026-09-22, feasibility / optimality / brainstorming go first
- rule: three use cases are first class, not aftermarket. feasibility (can this be built, what would kill it), optimality (which option wins the criterion), brainstorming (every option carries what would prove it before it leaves the round).
- why: the skill was originally shaped around defending a claim already on the table. most of the value is earlier than that. before a claim exists, while options are being weighed, while a plan's being sized. that's where the most effort gets wasted.
- how to apply: triggers include "is this feasible", "is this optimal", "compare options", "which is better", "help me decide", "brainstorm". opening move per class: feasibility, name the one missing measurement. optimality, write the criterion then run the check. brainstorm, every option carries the referent that'd prove it before it survives.
- promoted: 2026-09-22
